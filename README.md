# HWP Calculator

<img width="1920" height="960" alt="hwp BG" src="https://github.com/user-attachments/assets/fa07c3d4-30e2-457b-8356-49916e7606b5" />

a Windows 11 desktop app for calculating HWBOT Hardware Points (HWP) across benchmarks.

<img width="1124" height="780" alt="hwp dark light" src="https://github.com/user-attachments/assets/56dd1f1a-aa42-455a-b5f4-a14c1ef6cb27" />

built with WinUI 3 + Windows App SDK on .NET 8.

## features
- paste any HWBOT hardware URL and instantly see grouped HWP values
- filter by cooling method and HWP range
- expand benchmark groups to view individual submissions
- export results to CSV

## requirements
- Windows 10 1809 or later (Windows 11 recommended)
